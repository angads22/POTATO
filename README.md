# SLICE IT! · The Potato Cutting Championship

[![Latest release](https://img.shields.io/github/v/release/angads22/POTATO?label=latest%20release&color=gold)](https://github.com/angads22/POTATO/releases/latest)
[![All releases](https://img.shields.io/badge/releases-all%20versions-8B5A2B)](https://github.com/angads22/POTATO/releases)

A rhythm-action game about knives, starch, and questionable life choices. Chop potatoes
on the beat across six championship venues, play songs the game composes for you, run a
potato farm, or settle things in a first-person spud deathmatch.

**Every sound in the game is synthesized live.** There are no audio files and no image
files in this repository. The music, the knife chops, the sad trombone when you lose: all
of it is generated by code at runtime, from a seed.

## What's new in 4.0

- **A soundtrack.** The visual edition used to be completely silent. It now has a
  procedural synthesizer and composer: every venue, the farm, the town, the FPS arena and
  the menus play their own composed song, and every action has a sound.
- **Rhythm, for real.** The championship is locked to the music. Potatoes land on the bar
  line, the cut cursor crosses the centre on beat 3 (the snare), and the tempo climbs with
  each stage. FEVER fades an extra layer into the song, and the boss fight strikes on the
  kick and snare.
- **Concert mode.** A new note-highway rhythm mode. Potatoes ride a conveyor into the
  knife, and each one arrives on a note of a generated song. There's a Daily Song (the
  same for everyone, on every platform), a six-song setlist, and Random Jams whose seeds
  you can share.
- **A web edition.** Concert mode runs in any browser, phones included. It's one 89 KB
  HTML file with no install, and a seed composes the same song and chart there as in the
  desktop game.
- **Quality of life.** A pause menu (ESC no longer throws your run away), graded results
  with a full cut breakdown, music/effects volume, fullscreen (F11), screen-shake
  toggle, and an audio-latency calibration for Bluetooth headphones.
- **Console edition:** real sound on Linux and macOS, not just the terminal bell.

## The game

### Championship & Endless (visual edition)
- **Six venues, six songs.** Training Kitchen (lo-fi), Dinner Party (jazz), Street Food
  Stall (funk), Restaurant Kitchen (disco), TV Cook-off (game show) and World
  Championship (epic). Each song is faster than the last, and the venue itself
  escalates: bunting, then a crowd, then spotlights.
- **Five cut mechanics, all on the beat:**
  - *Slice*: cut on beat 3, when the cursor crosses the centre.
  - *Peel* (Purple Majesty): tap to start a gauge that fills over one bar, then tap again to lock it in the band.
  - *Speed Cut* (Fingerling): a double-time sweep whose sweet spot shrinks every beat.
  - *Julienne* (King Edward): two cuts, on 3 and then on the next 1. You're scored on the worse of the two.
  - *Rotten Potato*: don't cut it. Press **X** to bin it.
- **Golden potatoes** sweep double-time and pay 500 base points plus coins.
- **The Colossal Spud** boss caps the championship with an HP bar and a theme of its own.
- Combos, FEVER (4 bars of x2 plus a sparkle layer in the music), 3 lives, a life back
  every other stage, and a quick-cut bonus.
- **Results** show an S–D grade stamp, your PERFECT/GREAT/GOOD/MISS breakdown, accuracy,
  max combo and personal bests.

### Concert (visual + web editions)
Pick a song and a difficulty, then chop on the notes. Each song is the composer's 8-bar
loop arranged four ways: an **intro** where the chart follows the kick and snare, a
**verse** where the melody enters, a **chorus**, and a **finale** with extra accents.

| Note | What to do |
|------|------------|
| Potato | **SPACE** (or tap / left-click) as it reaches the knife |
| Sweet-potato ribbon | Hold **SPACE** until the tail passes |
| Rotten potato (green) | **X** (or right-click / the BIN pad) to bin it. Never chop it! |
| Golden potato | Worth triple, plus coins |

Misses drain the crowd's **HYPE** (empty means you're booed off stage) and make the melody
stumble. Streaks raise a x1–x4 multiplier, then FEVER doubles it. Easy, Normal and Hard
change the note grid, the density and the belt speed.

### The farm, the town, and SPUD BLASTER (visual edition)
- **Spudling Acres, the potato farm:** a cozy farm you check in on. Give each field a crop
  plan that fits your schedule, hire Spudlings who pick and replant while you're away (even
  with the game closed), and spend coins in the Farm Book, which shows how fast each purchase
  pays back for the way you play. Nothing rots, and a check-in is three clicks: Collect on
  Pip's note, catch the butterfly, make one decision. The farm is in the desktop builds only;
  on a Chromebook, play the web edition (Concert mode).
- **Town:** seed, knife and tool stalls around a fountain plaza, the championship kitchen,
  and the Concert Hall bandstand, which is a walk-up way into Concert mode. Knives you buy
  multiply your slicing score.
- **SPUD BLASTER:** a 3D first-person potato deathmatch. Practice against bots, host on
  your LAN, or host over the internet (automatic UPnP).
- **LAN duel:** two players cut the same potato sequence side by side.

## Controls

| | |
|---|---|
| Cut / chop | `SPACE` or left-click |
| Bin a rotten potato | `X` or right-click |
| Pause | `ESC` |
| Fullscreen | `F11` |
| Farm / town | Click anything, or `WASD` + `E` / `SPACE`; `F` field card, `T` tend all, `B` Farm Book, `Q` buy your goal, `G` catch the butterfly, `Z` zoom, `M` mute |
| SPUD BLASTER | `WASD`, mouse look, LMB to shoot, RMB to aim, `1`–`5` to switch weapons, `R` to reload, `SPACE` to jump |

**Audio feels off?** Settings → *Calibrate audio offset* plays a kick drum. Tap along and
the game measures your headphones' delay. (The web edition has a ± offset on its song
select screen.)

## Editions at a glance

| | Visual (`godot/`) | Web (`web/`) | Console (`PotatoSlicer/`) |
|---|---|---|---|
| Engine | Godot 4.2, GDScript | HTML5 canvas + WebAudio | C# / .NET 8 |
| Modes | Championship, Endless, Concert, Farm, Town, LAN duel, SPUD BLASTER | Concert | Championship, Endless, Time Attack, Daily |
| Music | Procedural soundtrack (`scripts/audio/`) | The same composer, ported (`web/core.js`) | Synthesized chimes |
| Install | Download and run | Open one HTML file | Download and run |

The editions share game design but not code. The one deliberate overlap is that the web
edition's `core.js` is a line-for-line port of the Godot composer and chart builder, and CI
checks the two produce identical songs and charts.

## Setting up the global leaderboard

The online leaderboard is opt-in and free to self-host on [Supabase](https://supabase.com):

1. Create a free Supabase project and run this SQL in the editor:
   ```sql
   create table sliceit_scores (
     id         bigserial primary key,
     name       text not null,
     score      integer not null,
     mode       text not null,
     knife      text,
     created_at timestamptz default now()
   );
   alter table sliceit_scores enable row level security;
   create policy "anyone can insert" on sliceit_scores for insert to anon with check (true);
   create policy "anyone can read"   on sliceit_scores for select to anon using (true);
   ```
2. Copy your **Project URL** and **anon public key** from Settings → API.
3. Give them to the game without editing source (keys are never committed), either via
   environment variables:
   ```sh
   export SLICEIT_SUPABASE_URL="https://xxxx.supabase.co"
   export SLICEIT_SUPABASE_KEY="<anon key>"
   ```
   or a git-ignored local config file at `user://supabase.cfg` (next to your save data):
   ```ini
   [supabase]
   url="https://xxxx.supabase.co"
   key="<anon key>"
   ```

The game works fully without this; scores stay local when no credentials are provided.

> **Security notes.** The anon key is safe to ship in a client *only* because Row Level
> Security gates what it can do. Keep the policies least-privilege and **never** use a
> `service_role` key here. Because credentials load from the environment or config rather
> than source, you can rotate the key in the Supabase dashboard with no rebuild. The client
> validates and rate-limits every submission, but a client can always be bypassed, so add a
> server-side `CHECK` constraint and a per-IP insert limit for defence in depth.

## Development

```sh
# Visual edition (Godot 4.2.2 in CI)
cd godot
godot --headless --import .                                             # compile check
godot --headless --path . res://tests/SmokeTest.tscn --quit-after 4000  # two stages + FEVER, on the beat
godot --headless --path . res://tests/ConcertSmokeTest.tscn --quit-after 6000
# …plus FarmSmokeTest, TownSmokeTest, FarmBalanceTest, FarmMigrationTest,
# FpsSmokeTest, BossSmokeTest (see CLAUDE.md)

# Web edition
python3 web/build.py                     # -> web/dist/SliceIt-Web.html (single file)
node web/tools/smoke.js web/dist/SliceIt-Web.html   # needs `npm i playwright`

# Console edition
cd PotatoSlicer && dotnet build -c Release
```

The smoke tests are auto-players. On the headless server the beat clock runs silently
(and 3x fast), so they drive the real beat-locked game logic in seconds.

## Cutting a release

1. Bump `VERSION` in `PotatoSlicer/Core/Updater.cs`, `<Version>` in the csproj, **and**
   `config/version` in `godot/project.godot`, all to the same `X.Y.Z`. Both in-game
   updaters compare against the release tag.
2. Tag the commit and push it: `git tag vX.Y.Z && git push origin vX.Y.Z`.
3. The Release workflow builds the console binaries, exports the Godot builds
   (Win/Linux/macOS), bundles `SliceIt-Web.html`, and publishes the release. A tag push
   marks it `latest`, so both desktop editions update to it.

**GitHub Pages (optional).** To host the web edition, enable Pages (Settings → Pages →
Source: GitHub Actions) and set the repository variable `PAGES_ENABLED` to `true`. Every
push to `main` that touches `web/` will then deploy it. You can also deploy on demand from
the *Web Edition* workflow.
